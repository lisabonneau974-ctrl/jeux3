# Feu Rouge Express

![Feu Rouge Express](images/banniere.png)

Viré de ton appartement, tu as fait croire à tes parents que tu vivais dans un bel appartement, avec canapé neuf et lampe design. Ils arrivent dans **30 jours** !

Lave les pare-brise des voitures arrêtées au feu rouge, rembourse ton ancien loyer à la banque, achète ton logement, retape-le et meuble-le avant leur visite.

## Jouer
Ouvre `index.html` dans un navigateur, ou active GitHub Pages sur ce dépôt.

## Commandes (modifiables dans ⚙ Réglages)
| Action | Touche |
|---|---|
| Marcher | ZQSD / WASD / flèches |
| Courir | Maj |
| Sauter | Espace |
| Agir / utiliser l'objet | E ou clic gauche |
| Objet en main | 1 à 4, R / F |
| Carte | M |
| Sac (inventaire) | I |
| Caméra | glisser la souris, molette pour zoomer |

## Technique
- Un seul fichier `index.html` (HTML, CSS, JavaScript)
- 3D avec [Three.js](https://threejs.org) r128 (`js/three.min.js`, licence MIT)
- Polices Fredoka et Nunito (`fonts/`, licence SIL Open Font License)
- Sauvegarde dans le navigateur (localStorage)
